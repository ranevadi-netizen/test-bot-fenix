# Fenix Logistics — Telegram Menu Test

Минимальный Telegram-бот для UX-тестирования сценариев Driver / Logistician / Client.

## Railway variable

Добавьте в Railway:

TELEGRAM_BOT_TOKEN=<новый токен из BotFather>

Не добавляйте токен в GitHub.

## Start command

Railway получает команду из `railway.toml`:

python bot.py

## Test

После успешного deploy откройте Telegram и отправьте боту:

/start
